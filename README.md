# HolisticSoap — Launch HQ

Scent-free, natural, coconut-forward handmade soap. Two partners, based in Kelowna, BC. Target: first sale within 2-3 months (by ~November 2026), startup budget $300-800.

**The positioning:** truly fragrance-free soap for sensitive skin and fragrance-intolerant people. It's a searchable keyword online ("unscented soap," "fragrance free"), a differentiator among ~100 market vendors, and a real procurement solution for health stores and wine-country B&Bs/spas. It also sidesteps Canada's new 2026 fragrance-allergen labelling rules entirely.

## Time-sensitive items (as of 2026-08-19)

1. **Craft Culture Holiday Market (Dec 4-6, Prospera Place)** — the Okanagan's biggest; applications fill up. Apply at craftculture.ca as soon as the name is registered.
2. **Downtown Kelowna Winter Street Market** — oversubscribed every year; apply the day applications open.
3. **KFCM 2026 is closed** — email Frances about Day Vendor openings; 2027 applications via marketmaestro.ca early in the year.
4. **BC PST registration** — required from ~day one of sales (no $30k grace like GST).
5. **Cure time is 4-6 weeks** — soap for December markets must be made by ~mid-October.

## Budget reality check ($300-800 envelope)

| Item | Cost |
|---|---|
| Test-batch setup (equipment + ingredients) | ~$180-230 |
| Business registration (name + partnership) | ~$70 |
| Kelowna business licence ($50 app + $160 manufacturing) | $210 |
| Domain + Etsy setup | ~$35 |
| **Subtotal: prove the product + legal shell** | **~$500-550** |
| First production run (100 bars, labels) | ~$390-470 |
| Insurance ($2M via HBBG) | ~$500/yr |
| Square reader | $0-59 |

The full stack overshoots $800 by roughly the insurance premium. Sequencing fix: spend on test batch + registration first; insurance and the production run can come out of a second tranche or the first market revenue target. Selling ~60 of the first 100 bars at $9 covers the whole production run + insurance.
