## The whole picture

| | |
|---|---|
| Total cash to first market | **~$1,450-1,800** |
| Revenue to fully recoup (at $9/bar) | ~160-200 bars |
| First production run yield | ~100-110 bars |
| Materials per bar (first run, with packaging) | $2.40-2.75 |
| Materials per bar (reorders, olive jug carries over) | ~$1.80 |
| Gross margin per $9 bar | ~$6.30-6.60 (70-73%) |

Break-even is roughly one good holiday market weekend plus trickle Etsy sales. Second production run costs only ~$160 in ingredients (the 12L olive jug is half full), so batch two is nearly all margin.
