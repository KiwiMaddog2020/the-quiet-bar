# Business Name Shortlist

Checked 2026-08-19 via WHOIS. A `.ca` domain is the right choice for a BC business (~$15/yr at CIRA-certified registrars like Porkbun, Namecheap, or Rebel.ca). All `.com` equivalents of the shortlist are taken, which matters little at this scale.

## Available .ca domains (as of check date)

| Name | Domain | Why it works | Watch out |
|---|---|---|---|
| **The Quiet Bar** | thequietbar.ca | "Quiet" = no scent. Distinctive, warm, memorable, zero competitors with this framing. Best storytelling name of the batch. | Could read as a pub name out of context; the tagline fixes that ("Soap with nothing to say — no scent, no dyes, no noise") |
| **Bare Bar Soap Co.** | barebarsoap.ca | Says exactly what it is: a bare, stripped-down bar. Alliterative, easy to spell aloud. | barebarsoap.com registered by someone else Oct 2025 — check they're not an active soap brand before committing |
| **Bare Lather** | barelather.ca | Same "bare" positioning, softer sound | barelather.com taken since 2020 |
| **True Lather** | truelather.ca | Honest/authentic angle | truelather.com registered June 2026 — recent, check who |
| **Okanagan Bare Soap** | okanaganbaresoap.ca | Strong local identity, great for farmers markets and tourist buyers | Long; ties the brand to the region if you ever expand |
| **Clean Slate Soap** | cleanslatesoap.ca | Nice double meaning (clean + fresh start) | cleanslatesoap.com is a 2014-registered domain, likely an existing brand — verify |
| **Scentless** | scentless.ca | One word, owns the niche | Slightly clinical; scentless.com long taken |
| **Simply Suds** | simplysuds.ca | Friendly, simple | Generic; several "Simply Suds" businesses exist elsewhere |

## Taken / avoid

- nakedcoconut.ca (registered 2014), plainandpure.ca (registered 2025)

## Recommendation

**The Quiet Bar** (thequietbar.ca) as first choice — it's the only name in the list that makes the scent-free promise *itself* the brand, which is the product's actual differentiator. **Bare Bar Soap Co.** as the safe, descriptive runner-up.

## Before committing to any name

1. Search the [Canadian Trademarks Database](https://ised-isde.canada.ca/cipo/trademark-search/srch) for conflicts.
2. Search Etsy, Instagram, and Google for active soap brands using the name (a domain being free doesn't mean the name is).
3. Run a BC Name Request (~$31) — required anyway to register the partnership under a business name.
4. Grab the domain, the Etsy shop name, and the Instagram handle the same day you decide.
